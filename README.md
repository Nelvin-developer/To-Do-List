📝 ToDo List – Java Console Application
📖 Overview

The ToDo List is a simple Java console-based application that allows users to add, view, and manage tasks efficiently. It helps in organizing daily tasks through a user-friendly interface built using core Java concepts like classes, objects, collections, and file handling.

🚀 Features

➕ Add new tasks

📋 View all tasks

✅ Mark tasks as completed

❌ Delete tasks

💾 Save and load tasks from a file (if implemented)

🧠 Concepts Used

Object-Oriented Programming (OOP)

Java Collections (e.g., ArrayList)

File I/O for saving tasks

Exception Handling

Loops and Conditional Statements


🛠️ Technologies Used

Language: Java

IDE: Eclipse / IntelliJ IDEA / VS Code

Java Version: JDK 8 or higher
